Web Node edition

The C-LVGL branch is the base for shared kernel and desktop work. Keep shared
fixes in their own commits so Web-Node can take them without importing a
runtime into C-LVGL. Both editions use tools/build-desktop-image.sh. The Web
Node entry point adds port/quotaos/wap/sources.list and a runtime payload
hook. ZIP decoding and manifest validation belong to the WAP extension.

The LVGL desktop owns the file picker, windows and input. Files passes an open
request to wap_open_saved() in port/quotaos/wap/app.c. That module validates the
ZIP and manifest, restores an existing app or asks the process service to start
its tier-3 processes. The desktop displays the published surface. The Demo
application lives in examples/demo; its HTML and scripts are ordinary app files.

port/quotaos/blink implements the Blink embedder, input and software paint.
port/quotaos/node provides the Node adapter. Both ends use port/quotaos/wap/rpc.js
for local RPC. The kernel owns admission, process identity, memory protection,
file access and IPC. The Linux ABI and ELF loader currently live in kernel/proc.c.

tools/build-node-web-runtime.py builds the two ARM64 executables with Chromium's
V8. tools/build-lvgl-guest.sh builds the common image. With QUOTA_NODE_WEB_OUT
set, tools/wap-runtime.sh embeds the executables and calls stage-wap-libraries.py
to collect their transitive dependencies, font, ICU data and V8 snapshot.
The packer checks that both executables resolve to the same libv8.so.

Image footprint

The two executables and their shared libraries are staged from the DT_NEEDED
closure. With LLVM objcopy, the image contains program segments without ELF
section headers; the source build retains its original ELF files. In Chromium
142, blink_core links the WebRTC component and media, and blink_platform links
GLES2 and gpu_config (which links Dawn). Removing those files alone breaks the
dynamic loader contract. Further reductions require a different Chromium
build configuration and a fresh guest acceptance run.

Historical WebCore and JSC prototype

Quota OS layers. Dependencies point downward.

1. Kernel (kernel/, boot/)
   Scheduling, three-tier admission, MMU, and the in-kernel framebuffer
   and input services. No HTML, CSS, or WebCore types.
   Tier-1 declarations stay the compiled constants. WebKit does not
   enlarge them. The EL1 identity map is page protection in one kernel
   address space. It is not separate-process isolation. That isolation
   is not implemented.

2. System services, transitional
   fb_reserve / fb_reserved_range and input_init live in the kernel.
   They are not protected service processes. A later transport can
   replace these entry points. Callers must not mask IRQs across a
   tier-1 slot. The WebKit guest runs on the tier-3 shell, so its CPU
   is the tier-3 quantum.

3. Platform adaptation (port/quotaos/, tools/generate-webcore-derived.sh)
   The only place that includes upstream WebCore. It calls kernel
   services. It does not talk to the UART, GIC, or page tables.
   Upstream generators write build/webcore-derived. Settings flags that
   CSSProperties.json names and Settings.yaml omits are bool settings
   defaulting to false, produced by that script.

4. Guest / demo
   quotaos_jsc_guest runs the JSC scripts and asks the platform adapter
   to paint. It does not parse CSS itself.
   lvgl_demo_run builds the button and the text field. It reads the
   input queue and draws through the flush callback. It does not touch
   virtio or fw_cfg.

LVGL image
   tools/build-lvgl-guest.sh
   Upstream v9.3.0, commit c033a98afddd65aaafeebea625382a94020fe4a7,
   licence third_party/lvgl/LICENCE.txt
   Output build/quotaos-lvgl.bin. Installed as prebuilt/quotaos.bin.
   prebuilt/quotaos-lvgl.bin is a copy of that file.
   prebuilt/quotaos-serial.bin is the previous serial drop-in.

Build targets
   tools/generate-webcore-derived.sh   headers from the pinned WebKit tree
   tools/link-jsc-guest.sh             JSC guest plus the WebCore objects
                                       listed in that script
   prebuilt/quotaos.bin                LVGL image, empty bootargs
   prebuilt/quotaos-serial.bin         previous serial drop-in
   prebuilt/quotaos-jsc.bin            JSC guest. Replace it only when the
                                       banner matches the parent commit.
