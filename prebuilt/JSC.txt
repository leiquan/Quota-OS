The 64 MB block at 0x44000000 is one parent reservation. Its children are
the structure heap 0x44000000-0x46000000 and the malloc arena
0x46000000-0x48000000. The parent contains the arena. The children do not
overlap each other. A guest test fills the arena, checks the structure-heap
canary, and stops at the last page. Log: docs/v016/jsc/webkit-color.raw.
The earlier image's log remains docs/v016/jsc/webkit-ownership.raw.

The current image retains the original engine objects and banner. Its 40-byte
stack switch was reassembled from kernel/jsc_stack.S at the existing ELF symbol
address. The resulting flat image differs only inside that function. The full
source link includes the same assembly via tools/link-jsc-guest.sh.
Run bash tools/run-webkit.sh for ramfb output. The verified capture contains
640 x 480 pixels of RGB (200, 0, 0). The serial log reaches guest returned 0
and [webkit] done. See docs/tests/webkit-stack/.
